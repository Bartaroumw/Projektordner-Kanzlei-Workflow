# FiBu-Lohn-Mehrfachsachverhalte

Ein Abstimmungsthema kann mehrere eigenständige Positionen enthalten. Damit lassen sich mehrere Arbeitnehmer, Reisen, Rechnungen oder Empfänger getrennt nachvollziehen.

## Positionsarten

- **Einzelposition** für einen konkreten Sachverhalt.
- **Sammelposition** für fachlich gleichartige Fälle. Sie ist nur bei Arbeitnehmer-Vorteilen, Reisekosten, Geschenken an Nichtarbeitnehmer und KSK zulässig.

Fahrzeuge und Scheinselbstständigkeit werden nicht als Sammelposition erfasst. Geschenk-Sammlungen verlangen eine Empfängerliste, KSK-Sammlungen eine Rechnungsliste. PDF- und XLSX-Dateien werden geschützt unter `storage/fibu-lohn` gespeichert und können einer Position zugeordnet werden.

Entwürfe dürfen vor der Gesamtübergabe gelöscht werden. Vollständige oder bereits übergebene Positionen werden nicht physisch entfernt, sondern nachvollziehbar archiviert oder korrigiert. Duplikate übernehmen keine Personen, Beträge oder Belege.

Die sichtbare Themenentscheidung lautet nur **Noch nicht geprüft**, **Kein relevanter Sachverhalt** oder **Sachverhalt vorhanden**. Die technischen Vollständigkeits- und Übergabestatus berechnet die Anwendung.
